# 🎙️ NoteGPT AI Provider — Gateway Architecture & Speech Engine

## 📌 نظرة عامة (Overview)
مزود **NoteGPT AI** داخل البوابة الموحدة (`__gateway-service`) يقدم قدرات مزدوجة فائقة القوة:
1. **الاستدلال البرمجي والساندبوكس (Agent Mode):** تشغيل نماذج `kimi-k3` و `deepseek-v4-flash` داخل بيئة سحابية معزولة (Daytona Sandbox) مع استخراج الملفات بنظام FIFO 10 مشاريع.
2. **توليد الصوت العصبي عالي النقاء (Neural Text-to-Speech):** توليد كلام طبيعي عالي النقاء بصيغة MP3 وتشفير Base64 ورابط CDN مباشر مع أصوات عربية فصحى طبيعية غير مدرجة في فلاتر الواجهة، وتدوير عناوين الـ IP عبر `proxy.txt` وبدون أي حسابات أو مفاتيح من جهة العميل.

---

## ⚙️ القدرات والعمليات المعتمدة (Capabilities & Operations)

| الخاصية | الحالة | التفاصيل |
|---------|--------|----------|
| **Credential Mode** | `platform` | صفر حسابات على المستدعي — الإدارة مؤتمتة بالكامل داخلياً |
| **Operations** | `generate_text`, `synthesize_speech` | استدلال نصي وتوليد صوتي متكامل |
| **Capabilities** | `chat`, `reasoning`, `code`, `audio_output` | دعم الشات والاستدلال والأكواد وتوليد الصوت |
| **Default Audio Format** | `mp3` | تسليم فوري لملفات MP3 عبر الـ CDN و Base64 |

## 🌐 تدوير الـ IP والبروكسي (Pure IP & Proxy Rotation)

- **الملف المرجعي:** `proxy.txt` داخل مجلد المزود.
- **التدوير التلقائي:** يتم توليد ترويسات `X-Forwarded-For` و `X-Real-IP` و `Client-IP` عشوائية مع كل طلب لمنع حظر الـ IP.
- **توقيع تشفيري صافٍ:** توقيع HMAC-SHA256 في بايثون الصافي بمفتاح `b"nc_ng_tts"` بدون الحاجة لأي محرك WASM أو Node.js لتوليد الصوت.
